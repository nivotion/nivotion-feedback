# Useful feedback, at any size

This is NIVOTION's first public Experimental Preview. A clear report can be short: explain what you tried, what you expected and what happened.

- Bugs: use the [Bug report form](PUBLIC_LINKS.md#bug-reports), including version and Windows details.
- UX: use [UX feedback](PUBLIC_LINKS.md#ux-feedback) for confusing screens, labels or steps.
- Improvements: use [Improvement idea](PUBLIC_LINKS.md#improvement-ideas) for a concrete problem and proposed benefit.
- Questions, general feedback and early impressions: use [Discussions](PUBLIC_LINKS.md#discussions).

Do not upload private or sensitive CSV contents. If data is needed, create a tiny synthetic CSV that reproduces the issue. Redact names, emails, customer data, local paths, tokens and private business data from screenshots, logs and attachments.

Security vulnerabilities belong in the product repository's private vulnerability reporting mechanism, never in public Issues or Discussions. If the private route is unavailable, wait until it is enabled; do not post the details publicly.

Search existing reports first if practical, then add useful detail or create a focused report. Be respectful and describe the behavior rather than the person. Czech and English are welcome. Suggestions are not roadmap commitments and no response-time guarantee is offered.
