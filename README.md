# NIVOTION feedback & community

## First Public Experimental Preview

This is NIVOTION's first public Experimental Preview. It is an early build, so rough edges are expected. Every useful bug report, confusing moment, workflow idea, missing detail and general impression helps us improve it. Suggestions are welcome; they are not roadmap commitments.

This is the community space for **nivotion-feedback**. Product documentation and Windows downloads live in the separate **nivotion** repository under the same GitHub owner. This repository contains no application source or release binary.

[Download NIVOTION](PUBLIC_LINKS.md#download) · [Feedback landing page](docs/index.html) · [Private security reporting](SECURITY.md)

## Choose the right conversation

| What you noticed | Where it belongs |
| --- | --- |
| Something did not work | [Bug report](PUBLIC_LINKS.md#bug-reports): version, Windows, steps, expected and actual behavior |
| Something was confusing | [UX feedback](PUBLIC_LINKS.md#ux-feedback): screen, expectation and confusing detail |
| An improvement would help | [Improvement idea](PUBLIC_LINKS.md#improvement-ideas): problem, suggestion and benefit |
| General impressions or a question | [Discussions](PUBLIC_LINKS.md#discussions): General feedback, Ideas, Q&A or Early impressions |

Do not upload private or sensitive CSV contents. If data is needed, create a tiny synthetic CSV that reproduces the issue. Redact names, emails, customer data, local paths, tokens and private business data from screenshots, logs and attachments.

Security vulnerabilities belong in the product repository's private vulnerability reporting mechanism, never in public Issues or Discussions. If the private route is unavailable, wait until it is enabled; do not post the details publicly.

English and Czech are welcome. Děkujeme za každý konkrétní postřeh — i drobná nejasnost nám pomůže. Nápad není příslib realizace.

Current product scope is Single CSV preparation with optional exact duplicate-original-row removal, and vertical append of 2–4 compatible CSVs with no automatic deduplication. Drafts are reviewed before explicit CSV/provenance export. English/Czech and Dark/Light are available. This is an early, experimental build, not a production-certified release.
